3dInteraction & transition annotations
Flow Bar appearScale 0.96→1 + fade, 160 ms spring. Anchored bottom-center of the display with the key window; follows the window across displays.
State morphPill width animates 200 ms ease-out; content cross-fades 120 ms. Left edge fixed, grows right. Never wraps, never taller than 40 pt.
Hotkey timingHold ≥ 250 ms = push-to-talk; two taps within 350 ms = hands-free toggle. Both modes are always active; Settings picks the default shown in hints.
ListeningWaveform 14 bars, 60 fps, driven by input RMS. Timer tabular. Hands-free auto-stops after 3 s silence (configurable 1–10 s). Max 15 min; at 14:30 the timer turns amber.
ProcessingStreaming: text is typed as segments finalize; the pill stays until the last token. If > 8 s with no output, label becomes “Taking longer…”; > 20 s → FB-05 with “Copy raw transcript”.
Auto-dismissInserted 1.5 s · Copied 2.5 s · Discarded 0.8 s · Didn’t catch / errors 4 s (or on any key). Idle pill hides after 6 s without focus in an editable field.
Popover / menusLanguage popover and Re-style menu: 120 ms fade + 4 px rise; dismiss on outside click, esc, or ⌥L. Arrow keys + return select.
Sheets & alertsSheets slide from the toolbar 250 ms; return = default button, esc = Cancel. Destructive default buttons are never focused by default (Delete, Remove, Stop).
Main windowSidebar switch is instant (no transition); window restores last page and size. Settings tabs are a segmented control; ⌘1–7 jump to sidebar items.
ProgressDownload and transcription bars update at 1 Hz; ETA smoothed over 10 s. Indeterminate (verifying, loading) uses the striped bar or dark spinner.
NotificationsOnly when the main window is not frontmost; only for completions (model, file). Never for errors that already have a Flow Bar state.
Toggles200 ms knob slide. Toggles that need a permission (Contacts, Launch at login) snap back if the permission is refused.
3eEdge cases & alternative paths
Mic busyAnother app holds exclusive input (FaceTime, Zoom) → FB-07 variant “Microphone in use by Zoom”; retries automatically when released.
Permission revoked laterAccessibility or Microphone removed in System Settings after onboarding → FB-07 / FB-04b; MW-01 shows the Setup card again (MW-01e pattern) with the red item.
fn already boundmacOS “Press fn key to: Change input source / Show emoji” → ST-02c banner at onboarding step 3 and in Hotkeys, with a one-click “Set fn to Do nothing”.
Secure inputPassword fields and apps with secure input enabled → FB-10; no audio is captured at all. Excluded apps list (ST-05) uses the same state.
Focus changes mid-dictationUser switches app while listening → text goes to the field that was focused at start; if it’s gone → FB-04b (Copied).
Long dictation> 60 s: processed in chunks, text streams in while you keep talking. 15 min hard cap → auto-stop and FB-04 with “15:00 · limit reached”.
Wrong language detectedAuto-detect confidence < 0.6 → chip shows “EN?”; clicking it opens FB-11 with “Re-run as …” options; History keeps the raw audio-free transcript only.
History offKeep history disabled (ST-05) → MW-02 shows MW-02e with “History is off”; Re-style and “Re-insert last” still work for the current session only.
Model files missingDeleted from disk manually → FB-08 and ST-03 row “Not installed”; no automatic re-download.
Sleep / quit mid-downloadResumes from the last byte on wake or next launch (MB-02 shows progress). Interrupted verification restarts from 0.
Onboarding abandonedQuit at any step → next launch resumes at that step; a completed permission is never asked twice. Menu bar icon exists from step 1.
Low Power Mode / thermalsProcessing slows → “Taking longer…” label; ST-03 suggests Parakeet for speed. Never switches models silently.
MCP port busy7331 taken → binds 7332…7340, ST-06 shows the actual endpoint with a note; clients must be updated (Copy button).
Multiple displays / full screenFlow Bar appears on the display of the key window, above full-screen apps and Stage Manager; hidden during screen recording if “Hide while recording” is on.
Files: duplicates & huge inputSame file dropped twice → single queue entry with a badge “2×”; > 4 h audio → confirmation with ETA before starting.
