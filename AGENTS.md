# Agent Instructions

This repository should be developed through small, focused pull requests.

Follow the pull request scope, PR template, and Conventional Commit rules in
[CONTRIBUTING.md](CONTRIBUTING.md), especially:

- Prefer PRs around 100-400 lines changed.
- Keep each PR focused on one coherent slice of work.
- Up to 800 lines changed is acceptable only for mostly mechanical changes.
- Avoid mixing architecture, UI, tests, refactoring, and documentation in one large PR.
- Use the documented PR template for every pull request.
- Use Conventional Commits for commit messages.

All commits must use the repository owner's configured Git identity. Do not
commit under any non-owner identity.
