# VoxFlow 2.1.2 — 2026-11-11

App/export version **2.1.2**, build **6**; hotfix from `master`, tag `v2.1.2`.

## Cause and correction

The crash log and local system diagnostics identified an uncaught AVFAudio tap exception:
the selected USB input was 48 kHz, while the cached client format was 16 kHz after Bluetooth
headphones became the system default. Swift `do/catch` could not catch this NSException.
Explicit inputs with noise suppression off now use a UID-pinned input-only AudioQueue,
independent of output-device negotiation. Other capture modes retain AVAudioEngine with an
Objective-C exception boundary and changed-buffer-format checks. See [ADR-010](../adr/010-selected-microphone-route.md).
