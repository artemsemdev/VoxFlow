## Changes and integration

- [#256](https://github.com/artemsemdev/VoxFlow/pull/256): 19 English/Russian real-model scenarios.
- [#257](https://github.com/artemsemdev/VoxFlow/pull/257): file speech detection, bounded timestamps
  and pause-aware dictation boundaries with sample preservation.
- [#258](https://github.com/artemsemdev/VoxFlow/pull/258): eight additional Russian recordings,
  from 16 seconds to 4 minutes 17 seconds, with exact ordered phrases and negation checks.
- [#259](https://github.com/artemsemdev/VoxFlow/pull/259): five-candidate recognition and optional
  whole-recording controls. Full references and outputs are archived in the repository.

The application code is the tested `5230ae5` implementation with the product version advanced.
Preparation also reconciles the previous master release's metadata and historical acceptance
records, which had not been merged back into develop. Release promotion retains both histories;
the cumulative master diff includes the reviewed transcription PRs, not unrelated new work.

## Accuracy and unverified scenarios

On the fixed synthetic Russian corpus, aggregate word error rate improves from 2.92% to 1.58%
on Turbo and from 4.95% to 4.75% on Small. This is not a real-speaker accuracy guarantee.
Small still loses a negation in one proposal/file case; both models have grammatical
substitutions. The [quality report](../testing/russian-recognition-fix.md) records every failure,
runtime and the limitations of the synthetic corpus. No acceptance threshold was weakened.

The physical scenarios in #137, #139, #144, #145 and #162 remain unverified in this release.
Their historical deferral for the previous release is preserved, and this publication does
not mark those issues passed or close them. See [hardware acceptance](../HARDWARE-ACCEPTANCE.md).
No privacy grants, onboarding state, models or History are reset as part of installation.

## Promotion and local installation

Require successful final PR CI before merging into master; publish the matching tag and verified
assets as the latest regular GitHub release. Merge the resulting release history back into
develop. The release page and PR checks are authoritative for publication and remote CI status.

Install the same verified artifact at `/Applications/VoxFlow.app` using `scripts/install_app.py`
after a normal app quit. The installer validates the designated requirement against the existing
app, stages on the destination filesystem and rolls back on verification failure. Launch that
path, verify bundle version/build and record installation evidence with the local build logs.
